# Deploying BizPilot AI on Render (100% Free Tier Guide)

This guide provides step-by-step instructions for deploying **BizPilot AI** (Milestone 4 Production Decision Engine with Automated Workflows and Observability Dashboard) to [Render.com](https://render.com) for free.

---

## 🚀 Architecture & Prerequisites

- **Stack**: Python 3.11, Flask, SQLAlchemy, LangGraph, APScheduler, Gunicorn, PostgreSQL.
- **Background Jobs**: In-process background worker using `APScheduler` backed by database job management (No Redis or Celery needed).
- **Prerequisites**:
  - A GitHub account with the project repository pushed to main.
  - A free account on [Render.com](https://render.com) (no credit card required).

---

## 🛠️ Step 1: Deploy with Render Blueprint (Recommended)

1. Log into your **Render Dashboard**.
2. Click **Blueprints** → **New Blueprint Instance**.
3. Connect your GitHub repository containing `render.yaml`.
4. Render will automatically detect `render.yaml` and configure:
   - **PostgreSQL Database** (`bizpilot-db` on Free Tier).
   - **Web Service** (`bizpilot-ai` running Gunicorn and auto-migrating with `flask db upgrade`).
5. Click **Apply**.

---

## ⚙️ Step 2: Configure Environment Variables in Render

In your Render Dashboard, navigate to your **Web Service** → **Environment** and set the required variables:

| Variable | Description | Recommended Value |
| :--- | :--- | :--- |
| `API_KEY` | Secret key for POST `/api/workflows/trigger` | Set a strong random secret string |
| `SECRET_KEY` | Flask session secret | Automatically generated by Render |
| `GEMINI_API_KEY` | Primary Gemini AI API key | Paste your Gemini API key (optional) |
| `GROQ_API_KEY` | Fallback Groq AI API key | Paste your Groq API key (optional) |
| `PRIMARY_AI_PROVIDER` | Default LLM provider | `gemini` |
| `FALLBACK_AI_PROVIDER` | Secondary LLM provider | `groq` |
| `ENABLE_RULE_BASED_FALLBACK`| Fallback mode when API keys unavailable | `true` |
| `WEBHOOK_URL` | Optional endpoint to receive POST results | `https://your-webhook-endpoint.com` |

---

## ⏰ Step 3: Keep Free Web Service Awake (UptimeRobot)

Render's free web services sleep after 15 minutes of inactivity. To keep your background **APScheduler** running continuously 24/7:

1. Create a free account at [UptimeRobot.com](https://uptimerobot.com).
2. Click **Add New Monitor**.
3. Select Monitor Type: `HTTP(s)`.
4. URL / IP: `https://your-bizpilot-app.onrender.com/api/health`
5. Monitoring Interval: `5 minutes`.
6. Click **Create Monitor**.

---

## 🧪 Step 4: Testing Your Deployment

### 1. Web Application & Dashboard
- Open `https://your-bizpilot-app.onrender.com`.
- Register/Login to access the **AI Decision Center** chat.
- Visit `https://your-bizpilot-app.onrender.com/dashboard` to view the real-time observability dashboard, agent latencies, and status breakdown.
- Access interactive OpenAPI/Swagger docs at `https://your-bizpilot-app.onrender.com/apidocs`.

### 2. Triggering Automated Workflows via REST API

```bash
curl -X POST https://your-bizpilot-app.onrender.com/api/workflows/trigger \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-strong-production-api-key" \
  -d '{
    "query": "Which products should I restock?",
    "webhook_url": "https://example.com/webhook"
  }'
```

Returns:
```json
{
  "success": true,
  "job_id": "c8f7e2b4-a901-4c30-9b4f-2a1d7c30e4f8",
  "status": "pending",
  "progress": 0
}
```

### 3. Checking Job Status & Results

```bash
curl -X GET https://your-bizpilot-app.onrender.com/api/workflows/jobs/c8f7e2b4-a901-4c30-9b4f-2a1d7c30e4f8 \
  -H "X-API-Key: your-strong-production-api-key"
```

## 🔄 Step 5: Database Migrations & Scheduler CLI

Database migrations run automatically during startup (`flask db upgrade && gunicorn app:app`).

To reload and synchronize scheduled jobs from the `WorkflowTemplate` table at any time:
```bash
flask sync-scheduler
```
